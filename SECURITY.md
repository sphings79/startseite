# Security policy / Sicherheitshinweise

**English:** Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the
[Security tab](../../security/advisories/new) instead of opening a public issue. Only the latest release is supported.

**Deutsch:** Sicherheitslücken bitte nicht als öffentliches Issue melden, sondern privat über „Report a vulnerability“ im
[Security-Tab](../../security/advisories/new). Unterstützt wird nur die jeweils neueste Version.
